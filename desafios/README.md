# Desafios

Atividades marcadas com `desafio: true` aparecem com o selo **Desafio** e valem até **+50 XP**
(contra +10 de uma atividade comum), desde que acertadas na primeira tentativa e sem dicas.

Situações usam dados de contexto: tabelas, consultas, tickets de suporte e código com bug.
Os desafios já vivem dentro das lições (procure o selo laranja), garantindo que nunca peçam
tecnologia que você ainda não estudou.

Novos desafios entram junto com as lições das próximas trilhas.
