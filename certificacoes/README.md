# Certificações

`certificacoes.js` mapeia credenciais externas relevantes (Microsoft, GitHub, Docker) para as
trilhas internas, com pesos. A tela **Certificações** calcula:

```
cobertura = soma(progresso da trilha × peso)
```

Quando a cobertura chega a 80%, o status muda para **Pronto para simulado**.

A plataforma **não emite certificados** — ela garante que você domine os conhecimentos
exigidos antes de investir na prova oficial.
